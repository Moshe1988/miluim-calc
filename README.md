# מחשבון זכאויות מילואים 🪖
**כלי פשוט וחינמי לחישוב ימי מילואים מצטברים והערכת מענקים לשנת 2026**

---

## 🎯 מטרת הפרויקט
לאור ריבוי סבבי השירות (פעימות) ומורכבות מערך התגמולים החדש של צה"ל, המחשבון נועד לעזור למשרתי המילואים לעשות סדר בזכאויות שלהם. 
המחשבון מסכם את סך הימים הקלנדריים הייחודיים (ללא כפילויות), ומציג אילו מענקים נצברו עד כה ומתי יושגו המדרגות הבאות.

## ✨ פיצ'רים עיקריים
* **חישוב ימים חכם:** חישוב מדויק של ימי מילואים גם אם יש מספר תקופות שונות (כולל פתרון התנגשויות תאריכים).
* **התאמה למדרגי שירות:** תמיכה במדרג לוחם (א'+), תומך לחימה (א'-ב') ועורף (ג' ומטה). ניתן להגדיר מדרג שונה לכל תקופת שירות!
* **הערכת מענקים מיידית (צו 8):** חישוב פרופורציונלי של מענקי "כלכלת בית/משפחה" (כל 10 ימים) ושל "התגמול המיוחד" היומי (החל מהיום ה-60).
* **מעקב מדרגות לתגמול הנוסף:** תצוגה ויזואלית של הדרך אל המדרגות השנתיות (10, 15, 20 ו-37 ימים למקסימום).
* **מעקב נקודות זיכוי מס:** ציון ההתקדמות לעבר 110 ימים (מקסימום 4 נקודות זיכוי במס הכנסה).
* **צפי תשלומים:** אלגוריתם שחוזֶה מתי תיפול הפעימה הבאה של מענק המשפחה ומתי יושג ה-60 יום, על בסיס המשך שירות רציף.

## 🚀 איך להשתמש? (Live Demo)
ניתן לגשת למחשבון ישירות מהדפדפן וללא כל התקנה בקישור הבא:
👉 **(https://moshe1988.github.io/miluim-calc/)[מחשבון 2026]**

1. היכנסו למחשבון.
2. לחצו על בחירת התאריכים (ייפתח לוח שנה).
3. בחרו תאריך התחלה ותאריך סיום עבור אותה פעימה (אם זה יום אחד, לחצו עליו פעמיים).
4. בחרו את מדרג השירות שלכם לאותה פעימה (לוחם/תומכ"ל/עורף).
5. במידה ויש תקופות נוספות, לחצו על "+ הוסף תקופה" וחזרו על הפעולה.
6. לחצו על "חשב זכאויות וצפי" וקבלו את התמונה המלאה.

## 🛠️ טכנולוגיות
המחשבון נבנה כקובץ מקומי יחיד ללא תלות בשרת צד שלישי (Client-side בלבד), מה שמבטיח פרטיות מלאה.
* HTML5
* CSS3 (עיצוב רספונסיבי למובייל)
* Vanilla JavaScript (לוגיקת חישוב)
* **[Flatpickr](https://flatpickr.js.org/)** - עבור בורר התאריכים.
* **[Font Awesome](https://fontawesome.com/)** - עבור הסמלים.
